# 双色面性图标绘制规范

按这份规范画出的图标，和 `icons.mjs` 里的 26 个范例属于同一套：16 网格、实心、两种颜色，物体主体用浅色，关键部件和细节用主色。每一条都是硬性要求。

## 流程

1. 读完这份规范。
2. 确定在哪里做：往这套范例里加，直接在 `icons.mjs` 里追加；给别的产品做新一套，把 `kit.mjs`、`icons.mjs`、`motion.mjs`、`check.mjs`、`export.mjs`、`chrome.mjs` 复制到目标位置，在副本里工作。范例先留着，画完对照着检查；交付前再删掉用不到的。
3. 读产品代码或功能清单，给每个功能定一个物体（第 1 节）。
4. 每个图标选关键形状（第 2 节），先读结构最接近的范例（第 8 节），再画。
5. 运行自检（第 9 节），把 Findings 清空，再对照清单看截图。
6. 导出（第 10 节），告诉用户用的主色和辅色。

## 0. 适用范围和交付

- 交付静态 SVG，`viewBox="0 0 16 16"`，可以缩放到任意尺寸。没有动效。
- 只做双色，不做单色版，也不做三种以上颜色的多色版。
- 适合界面里 16–48px 的功能图标：导航、按钮、列表、标签页。
- 绘制工具在 `kit.mjs`，范例在 `icons.mjs`，自检用 `check.mjs`，导出用 `export.mjs`。不要另写一套几何或渲染代码。

## 1. 选物体

- 物体要是现实里一眼认得的东西，从正面画。
- 用户点名的是功能（首页、搜索、设置、分享）而不是物体时，先给功能找一个物体或通用符号，再按下面的规则画。
- 只用矩形、圆角矩形、胶囊、圆和圆弧拼。不用斜线、倾斜摆放、透视和自由曲线。上窄下宽的袋子、喇叭口的铃铛、水滴形的蝴蝶结都属于这一类。
- **例外：约定俗成的界面符号可以用 45° 斜边。** 只限下面这些，大家认得它们靠的就是这个角度：
  - 房子的屋顶（首页）
  - 放大镜的手柄（搜索）
  - 齿轮的齿，按 45° 的倍数旋转（设置）
  - 箭头的箭头部分（下载、上传、分享、返回）
  - 斜放的笔（编辑）
  - 对勾、叉号（关闭）
  - 播放三角：保持常见的比例（宽约为高的 0.78），不受 45° 限制，按重心居中（见 `play`）
  
  斜边的写法见第 8 节的 `polygon`、`rot`。斜边和其他边相接的角照样按第 4 节取圆角，尖顶也要圆角，不出现尖角。表里没有的物体仍然不用斜线。
- 自己挑物体时，需要斜线才能画出来、又不在上面例外里的物体，换一个。用户点名的物体，用圆弧代替斜线，不要换物体：信封盖画成下沿是圆弧的盖子（见 `mail`），书签底部的 V 形缺口画成半圆缺口。
- 不出现尖角和细颈：不画尖尾巴、尖角、两条弧线收成的尖点。屋顶尖、箭头尖、播放三角的角都用圆角收住：尖顶至少 1；小箭头头部的两个侧角可以用 0.5，否则箭头会变成一团。心形用两个圆和两段相切的圆弧拼，底部的尖用圆角收住（见 `heart`）。
- 斜边的尖顶被圆角收进去之后会变矮。把尖点画到参考线外面一点，让圆角后的轮廓正好落在参考线上（见 `home`）。
- 表示动作的功能（下载、上传、分享）要有一个浅色主体承载箭头，例如一个盒子；只画一个箭头时，没有浅色主体，不符合第 3 节。对话气泡用"一个角是直角"来表示说话，不画尾巴。
- 每个图标都要在 24px 和 16px 下各看一次，确认不会被认成别的东西。出现歧义时，先加一个能说明身份的部件，再不行就换物体。下面是已经确认过会认错的画法，不要再用：
  - 钱包上一个大圆扣：像眼睛或摄像头。扣子要小，收在钱包里面。
  - 圆顶加一条平檐的铃铛：像餐盖。铃铛要有铃舌，檐只有 1.75 高。
  - 两块并排的楼：像柱状图或电池。建筑画成一栋楼，配两列窗条和一扇门。
  - 两个实心圆的蝴蝶结：像一双眼睛。蝴蝶结画成两个圆环加一个结，在盒盖上方隔一个线宽。
  - 一页六条线的书：像柜子。每页最多两条线。
  - 两个半圆的山：像两团东西。图片里只画一座山和一个太阳。
  - 购物袋和锁轮廓相同：靠提手和锁梁的粗细、锁孔区分。

## 2. 画布、参考线和尺寸

- 活动区 14×14（1..15），四周留 1，任何东西都不能超出。
- 每个图标选一个关键形状，写在 `key` 里，整体轮廓（连同凸起、提手、立柱、蝴蝶结）正好填满它：

| key | 尺寸（位置） | 用在 |
| --- | --- | --- |
| `circle` | 直径 14，圆心 (8, 8) | 表盘、脸、球 |
| `square` | 13×13（1.5..14.5） | 日历、相机、用户、建筑、铃铛、礼物、归档盒 |
| `landscape` | 14×12（y 2..14） | 文件夹、证件、书、图片、钱包、对话 |
| `wide` | 14×11（y 2.5..13.5） | 现实里长边是短边 1.4 倍以上的物体：票、云、电池、信封 |
| `portrait` | 12×14（x 2..14） | 文件、锁、垃圾桶、话筒、购物袋 |
| `tall` | 10×14（x 3..13） | 现实里就瘦高的物体：手机、瓶子。按 12×14 画会被认成平板 |
| `flat` | 14×8（y 4..12） | 靠又长又矮的轮廓认出来的符号：链接、滑块。按 14×11 画，链接会像圆圈里一个减号 |
| `live` | 14×14 | 左右分开的物体，比如耳机 |

- 内部细节放在中心直径 8 的内圆附近。
- `square` 图标在 12×12 的框里（2..14）画，渲染时以中心放大到 13×13，让方形和矩形面积相当；描边和缝的宽度会换算回来，粗细不变。
- 不强制对齐整数像素，坐标可以落在 0.5、0.25 上。
- 不要把横向物体画成 14×10，也不要把竖向物体画成 10×14：前者显得扁，后者显得瘦长。只有本身就长的物体用 `wide`。
- 实心图标比同尺寸的线性图标看起来大，所以轮廓比线性图标的外框小一点是对的，不要为了"撑满"把它放大。

## 3. 颜色

- **主体一律用辅色。** 物体本身（纸、盒子、表盘、钱包、文件夹、气泡、话筒头）是浅色，写 `Bt`。
- **主色只做点缀。** 主色只用在说明身份的关键部件和细节上：锁梁和锁孔、镜头圈、字线、指针、扣子、电量格、提手、耳罩、话筒支架、蝴蝶结和丝带。
  - 主色只是细节（线、点、指针、小部件）时，一般在三分之一左右或更少。
  - 主色是物体的一个大部件（屏幕、信封盖、耳罩、送出的纸、放大镜圈）时，可以更多。
  - 不管哪种，都不能超过 60%。
- **印在主体上的细节和主体直接相接，不留白缝。** 主色细节完全印在浅色主体里面时，靠深浅区分，不加白边。分开的元素，以及跨过另一个元素边缘、压在它上面的元素，不管什么颜色，都按第 6 节处理：隔一个线宽，或者用白色描边蒙版切开。
- **白色只用在两处：**
  - 几何上把一个物体分开的缝，比如盖子和箱体、书的两页、票和票根。
  - 主色部件上本来就是孔的地方，比如镜头中心、钱包扣的扣眼。
- 默认配色：主色 `#4767F0`，辅色 `#B5C2F9`。辅色等于主色 40% 透明度叠在白底上的颜色。换品牌色时用 `secondary(主色)` 推导，不要另挑。
- 辅色必须是主色同色相的浅色，不用灰色，也不能比 40% 更淡：太淡时，浅色主体在 16px 下撑不住轮廓，白缝也会看不清。

## 4. 圆角

**4.1 半径由角在物体上的位置决定，不强行用一种。** 尺寸按画的时候的数值量，`square` 图标按放大前的 12×12 框量。

| 角的位置 | 半径 | 常量 | 例子 |
| --- | --- | --- | --- |
| 横向主体（14×12，`landscape`）的外轮廓角 | 3 | `R3` | 证件、图片、钱包、书、对话 |
| 其他主体，短边 9.5 及以上 | 2.5 | `R` | 文件夹、相机、日历、建筑、电池、票、信封、箱体底部、购物袋 |
| 竖向主体（12×14 的纸、书本），以及短边 6 到 9.5 之间 | 2 | `M` | 文件、锁体、打印机机身 |
| 短边 3.5 到 6 之间 | 1.5 | `r` | 凸起、票根、耳罩、盒底、证件照片 |
| 短边小于 3.5 的小部件（门、烟囱、把手、箭杆） | 短边的一半以内，常用 0.5–1 | | 门上角用 1，箭杆两端用整个半圆 |
| 切缝：一条缝笔直穿过同一个轮廓，两侧对齐 | 0 | | 书的两页、票和票根 |
| 接缝：窄的部件在宽的部件旁边，隔着缝露出自己的角 | 1 | `S` | 盖子下面的箱体、袋口 |
| 薄片：盖子、横条、底座 | 厚度 × 0.4，按 0.25 取整 | `q`、`t` | 1.5 厚用 0.5，2 厚用 0.75，2.5 厚用 1，3.5 厚用 1.5 |
| 内角：凸起和主体相接 | 0 | | 文件夹标签、相机顶部、盖子把手 |
| 孔 | 外圆角减壁厚 | | |
| 本身就是圆的 | 整圆、半圆、胶囊 | `circ`、`pill` | 表盘、脸、话筒头、铃铛、肩部、线头 |

- 外轮廓角约为物体短边的 0.24 倍；竖向的纸和书本小一档，显得挺括。
- 除了线头和很小的细节，不用小于 1 的圆角。小圆角太多会让整套图标显得油腻。
- 切缝两端保持直角，缝看起来就是一条切线。如果在切缝两端做小圆角，轮廓上会出现缺口。
- 不加倒角：凸起和主体相接处保持直角，倒角会让部件糊在一起。
- 同一个部件不要随意一边圆一边方。只有三种情况可以：切缝两侧、接缝两侧，以及从开口里伸出来的部件被开口切断的那一边（打印机送出的纸，见 `printer`）。
- 每个部件都用完整的大圆角时，一个物体会散成几块软垫。所以一个物体被分成几部分时，它的外轮廓仍然要是一个完整的圆角形。

**4.2 平滑角。** `kit.mjs` 的 `poly` 已经实现，直接用 `rr`、`body`、`pill`，不要自己画圆弧角。做法和 Hugeicons 相同：每个角用两段曲线，曲线从离角 1.8 倍半径处开始，中点落在同半径正圆弧经过的位置。所以看起来就是这个半径，但和直边衔接时没有折点。

## 5. 细节

- 线和槽宽 1.25（`D`），成组的点半径至少 0.625，描边 1.5（`K`：锁梁、提手、指针、箭杆），细支架 1.25（话筒支架、耳机头梁）。用浅色描边画出来的主体（链接的两个半环）用 2，不然在 16px 下撑不住。
- 印在主体上的小细节（线、点、槽、小标记）离主体边缘约 3，至少 2，不要贴边。物体本身的部件（屏幕、信封盖、从顶边垂下的书签带、伸出的纸、站在底边上的门、开关的拨钮）属于轮廓的一部分，可以贴边，不受这一条限制。
- 一个面上最多两到三条线：文件三条，书每页两条，对话两条。
- 细节要轻：线太粗、点太大、离边太近，都会显得稚嫩。
- 表盘类（时钟、笑脸）是浅色表面，指针和五官用 1.25–1.5 的主色线条。不加外框，加了会像线性图标。

### 5.1 小部件的最小尺寸

在 22–24px 的列表和标签栏里，单独的小部件最容易显得过小。按部件的角色分三类，尺寸都按 16 网格、画出来的实际大小算。下限对照 Solar Bold Duotone 和 Duo Icons 量出来：它们的锁孔面积约 5.6、铃锤 4.8–9.6、文件夹上的线长约 4.3；成组的格点只有直径 1 左右。

| 角色 | 例子 | 下限 |
| --- | --- | --- |
| 单独的小标记 | 锁孔、铃铛的钮和铃锤、门 | 面积至少 4：圆点直径至少 2.25，槽至少 1.5×3 |
| 单独的一条线 | 文件夹上的标签、证件和手机上的线 | 长度至少 3，宽 1.25 |
| 成组的部件（两个及以上一样大） | 日历格点、窗户、书页文字、眼睛 | 点直径至少 1.25（面积 1.25），线长至少 2.25 |

- 面积 8 以上的是部件，不是细节，不受这张表限制。
- 放不下就删掉，不要缩小。离边至少 2 的要求和这张表冲突时，说明这个细节不是认出物体所必需的，例如相机的闪光灯、打印机的指示灯，直接去掉。
- 放大时按物体的样子放大：铃铛的钮是圆的，铃锤是半圆的，不要只是把原来的小块拉宽拉长。
- 自检的 `size` 规则会量出每个主色小部件，并按上表判断。

## 6. 间距、遮挡和对齐

- **分开的元素之间至少隔一个线宽 `W`（1），而且正好是 1。** 刚好贴着（0）和差一点（0.5）都不行，飘出去 2 以上也不行。例如头和身体、盖子和箱体、书的两页、票和票根、蝴蝶结和盒盖、购物车的车筐和车架、话筒头和支架。
- **一个元素压在另一个元素上面时，前面的元素加一圈宽 `W` 的白色描边蒙版（`gap: W`），把后面的元素切开。** 这样两个元素之间同样隔着一个线宽，又能看出谁在前。例如：
  - 云挡住太阳。
  - 锁体挡住锁梁，袋身挡住提手。
  - 耳罩挡住头梁，镜片挡住放大镜手柄。
  - 符头挡住符干。
  - 箭头压在盒子上（下载、上传、分享）。
  - 日历的立柱、铃铛顶上的钮、定位的刻度跨过主体边缘。
  - 打印机送出的纸压在机身上。
- 叠放要有明确的遮挡关系：后面的元素被前面的盖住一块，约四分之一到三分之一，一眼看得出谁在前、谁在后。只擦到边的叠放看不出关系（见 `cloud`）。
- 一个元素由几层组成时（箭头的箭杆和箭头头部），给这几层写同一个 `part`，它们的蒙版不会互相切开。
- 以下几种不算分开的元素，不受这一条限制：
  - 完全印在主体里面的细节（字线、点、指针、表情、窗条、站在底边上的门）。
  - 用 `clip` 从主体上截出来的部分（信封盖、笔尖）。
  - 同一主体上的主色细节之间的距离（眼睛和嘴），按第 5 节处理。
- **关系要规整。** 相关的元素对齐到同一条中线或同一条边上：
  - 分享、下载、上传的箭杆落在盒子的中线上。
  - 门、锁孔、钮、铃舌、底座落在主体的中线上。
  - 成对的部件（耳罩、轮子、眼睛、窗条）以主体为中心对称，例如购物车的两个轮子以车筐为中心。
  - 一组细节（字线、点）左边对齐，间距相等。
- **嵌在主体里的部件，到它靠近的几条边的距离必须相等。** 靠近指 2.6 以内。放在圆头里的圆和圆头同心：开关的圆钮离轨道上、下、外侧都是 1，不能上下 0.75、侧边 1.5。放在角上的部件离两条边一样远：图片里的太阳离上边和右边都是 2.25。只靠近一条边的（锁孔、字线）按居中或左对齐处理。挂在边上或站在边上的部件（书签带、门）属于轮廓的一部分，不算。

## 7. 切割

- 一个物体最多分成两到三部分，比如盖子和箱体、头和身体。各部分不再继续切开。
- 丝带、指针、字线这类细节直接印在主体上，不用白线把它们切出来。

## 8. 写法

- 新图标按 `icons.mjs` 的格式追加：

  ```js
  名字: {
    label: '中文名',
    key: 'landscape',
    layers: [
      L(rr(1, 2, 14, 12, R3), Bt),            // 浅色主体
      L(pill(9.5, 6.25, 4.5, 3.5))            // 主色部件
    ]
  }
  ```

- `layers` 按从后到前的顺序写：一般先写浅色主体，再写主色部件和细节。现实里浅色部件在前时，浅色就写在后面，例如太阳藏在云后（`cloud`），音符的符头压住符干（`music`）。
- 工具函数：
  - `rr(x, y, w, h, 半径或[左上, 右上, 右下, 左下])`：圆角矩形。
  - `polygon([[x, y], ...], 半径或每个点一个半径)`：任意多边形，按顺时针给点，每个角都按第 4 节平滑处理。只用来画第 1 节例外里的斜边，例如屋顶、箭头头部、播放三角。
  - `rot(cx, cy, w, h, 角度, 半径)`：以 (cx, cy) 为中心、旋转一定角度的圆角矩形。用来画放大镜手柄、齿轮的齿、斜放的笔。
  - `pill(x, y, w, h)`：胶囊。
  - `circ(cx, cy, r)`：圆。
  - `body(x, y, w, h, 半径, [{ x, w, h, c }])`：顶边带凸起的主体。
  - 描边写 `L(路径, { sw: K })`，镂空写 `cut: [C(形状)]`。
  - `clip: 形状`：只画这一层落在形状里面的部分。用主色画主体的一部分时用它，部件和主体的圆角完全一致，例如信封盖是主体被一个圆截出来的上半部分（见 `mail`）。不要用全画布矩形加反向路径去凑。
  - `gap: W`：在这一层的轮廓外切出一圈宽 `W` 的白缝，把它下面的层切开。前面的元素压在后面的元素上时用它（第 6 节）。
  - `part: '名字'`：几层属于同一个元素时写同一个名字，它们的 `gap` 不会互相切开。
- 每画一个图标之前，先在 `icons.mjs` 里读一两个结构最接近的范例：
  - 带盖的看垃圾桶和归档盒。
  - 一分为二的看书和票。
  - 带凸起的看文件夹和相机。
  - 表盘看时钟和笑脸。
  - 箭头类看下载、上传、分享；斜放的物体看编辑（笔）和搜索；用斜边拼的看首页、播放、心形。
  - 瘦高的看手机（`tall`），扁长的看链接（`flat`）。
  - 主体的一部分用主色的看信封；从开口里伸出东西的看打印机。
  - 带提手或锁梁的看锁和购物袋。
- 确认是有意为之的检查结果，可以在图标里写 `allow: { 规则名: '理由' }` 声明，例如话筒立柱顶端藏在支架后面。没确认过的不要声明。

## 9. 自检

```bash
node check.mjs --only 新图标A,新图标B --with folder,lock,calendar
```

输出在 `check-out/`：

- `sheet.png`：64px（带像素网格）、48、24、16px。
- `keylines.png`：每个图标叠在参考线上，红线是它选用的关键形状。
- `px16.png`：1 倍屏下真实的 16px，放大 4 倍。
- `findings.md`：能量化的规则逐个测量的结果：
  - `keyline`：轮廓没有填满关键形状（差 0.25 以上）。
  - `primary`：主色超过着色面积的 60%。
  - `tones`：只用了一种颜色。
  - `spacing`：分开的元素之间不是正好隔 1（刚好贴着也算）。
  - `overlap`：一个元素压在另一个元素上，却没有白色描边蒙版。
  - `size`：主色小部件小于第 5.1 节的下限。
  - `inset`：嵌在主体里的部件到靠近的几条边的距离不相等（相差超过 0.15）。
  - `motion`：`motion.mjs` 里的动效指向了图标没有的层。

`findings.md` 的 Findings 必须清空：要么改图，要么确认后用 `allow` 声明。然后对照截图，逐条检查下面的清单：

1. 在 24px 和 16px 下认得出是什么，不会被认成别的东西（第 1 节）。
2. 轮廓填满关键形状，和 `--with` 带进来的范例看起来一样大。
3. 主体是浅色，主色只在关键部件和细节上，两色之间没有白缝。
4. 每个角的半径符合第 4 节的表；没有尖角，没有倒角，没有随意的一边圆一边方。
5. 细节的线宽、点径、离边距离符合第 5 节，小部件不小于第 5.1 节的下限，一个面上的线不超过三条。
6. 分开的元素正好隔 1；压在别的元素上的元素带着 `gap: W` 的白边；相关元素对齐中线、成对的部件对称；嵌在主体里的部件四周边距一致。
7. 物体最多分成两到三部分。

## 11. 动效

在网页里，图标可以带悬停动效，写在 `motion.mjs`。导出的静态 SVG 不受影响。

- **动效必须是物品真实会做的动作。** 例如：
  - 盖子绕铰链掀开，日历撕下一页，书翻过一页。
  - 分针走一圈、时针走一格，钥匙插进锁孔转一下，眼睛眨一下。
  - 滑块滑到另一头，地球自转。
  - 对勾、叉号按笔画重新写一遍；按钮类按下再弹起。
  
  不用单纯的放大、缩小或脉动。想不出真实动作时，换一个动作，不要凑。
- **部件按现实中的连接方式运动。** 盖子绕铰链转，提着的袋子绕提手晃，几个部件各动各的（两根指针速度不同、两个耳罩各自向里夹）。原来画在同一层、要分开运动的部件，拆成几层；拆开后外观不变。
- **节奏。** 悬停时用 650ms、曲线 cubic-bezier(.33, 1, .68, 1) 走到一个姿态并停住，移开后用 520ms 沿同一曲线退回。幅度要小：移动 0.5–1.5，转动 5–20°，缩放 0.8–1.2。摆动、震动这类带关键帧的动作，关键帧按时间均分，每多一段加 140ms；手机震动这类快速抖动用 `ms` 单独定总时长。
- **写法。** `MOTION[名字] = { say, moves, copy?, ms? }`：
  - `say`：一句中文，说明物品做了什么动作。
  - `moves`：把层号（或 `all`，表示整个图标）对应到一个姿态。可用的键有 `x`、`y`（移动），`r`（转动），`s`、`sx`、`sy`（缩放），`a`（透明度），`w`（笔画画出的比例），`o`（转动和缩放的中心）。
  - 每个键的值可以是悬停时停住的值，也可以是一串关键帧。
  - `copy`：复制几层盖在原位，用来表现"下面还有一页"，撕下或翻走的是复制出来的那一层（见 `calendar`、`book-open`）。
- **静止时看不见的部件。** 可以完全藏在主体后面，动的时候再出来，例如文件夹里抽出的纸（见 `folder`）。它必须完全被挡住，静态外观不能因此改变。
- **自检。** 在展示页里逐个悬停检查，不能只看静态截图：
  - 动作是否符合物品的真实动作。
  - 白色描边蒙版是否跟着部件一起动。
  - 移开后是否回到原位。
