# 双色面性图标绘制规范

本规范定义 `icons.mjs` 中 81 个范例所属的图标风格：16 网格，实心，两种颜色；物体主体用浅色（辅色），关键部件和细节用主色。以下各条均为硬性要求。

## 流程

1. 通读本规范。
2. 确定工作位置。向现有一套添加图标时，直接在 `icons.mjs` 中追加；为其他产品新建一套时，将 `kit.mjs`、`icons.mjs`、`motion.mjs`、`motions.mjs`、`check.mjs`、`export.mjs`、`chrome.mjs` 复制到目标位置，在副本中工作。范例保留到自检完成，交付前删除不用的部分。
3. 根据产品代码或功能清单，为每个功能确定一个物体（第 1 节）。同一物体的新建、完成、删除、AI、关闭等状态，用角标做成变体（第 12 节），不另选物体。
4. 为每个图标选定关键形状（第 2 节），阅读结构最接近的范例（第 8 节），然后绘制。
5. 运行自检（第 9 节），清空 Findings，再按清单检查截图。
6. 导出（第 10 节），并告知用户所用的主色和辅色。

## 0. 适用范围

- 交付物为静态 SVG，`viewBox="0 0 16 16"`，可任意缩放。需要动效时，另加悬停动效（第 11 节）。
- 只做双色版本，不做单色版，也不做三色及以上的多色版。
- 适用于界面中 16–48px 的功能图标：导航、按钮、列表、标签页。
- 几何与渲染一律使用 `kit.mjs`，不另写实现。范例在 `icons.mjs`，自检用 `check.mjs`，导出用 `export.mjs`。

## 1. 选物体

- 选现实中一眼能认出的物体，画正面。
- 用户给出的是功能（首页、搜索、设置、分享）而不是物体时，先为功能选定一个物体或通用符号。
- 只用矩形、圆角矩形、胶囊、圆和圆弧组合。不用斜线、倾斜摆放、透视和自由曲线，因此不画上窄下宽的袋子、喇叭口的铃铛、水滴形的蝴蝶结。
- **例外：以下约定俗成的界面符号可以用 45° 斜边**，因为人们正是靠这个角度认出它们：
  - 房子的屋顶（首页）
  - 放大镜的手柄（搜索）
  - 齿轮的齿，按 45° 的倍数旋转（设置）
  - 箭头的头部（下载、上传、分享、返回）
  - 斜放的笔（编辑）
  - 对勾、叉号
  - 播放三角：保持常见比例（宽约为高的 0.78），不受 45° 限制，按重心居中（见 `play`）

  斜边用第 8 节的 `polygon`、`rot` 绘制。斜边与其他边相接的角仍按第 4 节取圆角。不在上表中的物体不用斜边。
- 自选物体时，需要斜边才能画出的物体一律换掉。用户指定的物体不换，用圆弧代替斜边：信封盖画成下沿为圆弧的盖子（见 `mail`），书签底部的 V 形缺口画成半圆缺口。
- 不出现尖角和细颈，包括尖尾巴、尖角和两条弧线收成的尖点。屋顶、箭头、播放三角的尖顶圆角至少 1；小箭头头部的两个侧角可用 0.5，否则箭头难以辨认。心形由两个圆和两段相切的圆弧组成，底部尖点倒圆（见 `heart`）。
- 尖顶倒圆后会变矮。将尖点画到参考线外，使倒圆后的轮廓正好落在参考线上（见 `home`）。
- 表示动作的功能（下载、上传、分享）需要一个浅色主体承载箭头，例如一个盒子；单独一个箭头没有浅色主体，不符合第 3 节。对话气泡用一个直角表示说话，不画尾巴。
- 每个图标在 24px 和 16px 下各检查一次，确认不会被认成别的物体。有歧义时，先加一个能说明身份的部件；仍有歧义就换物体。以下画法已确认会被认错，不再使用：
  - 钱包上一个大圆扣：像眼睛或摄像头。扣子要小，收在钱包内。
  - 圆顶加一条平檐的铃铛：像餐盖。铃铛要有铃锤，檐高 1.75。
  - 两栋并排的楼：像柱状图或电池。画成一栋楼，配两列窗条和一扇门。
  - 两个实心圆的蝴蝶结：像一双眼睛。画成两个圆环加一个结，与盒盖隔一个线宽。
  - 一页六条线的书：像柜子。每页最多两条线。
  - 两个半圆的山：像两团物体。图片中只画一座山和一个太阳。
  - 购物袋和锁轮廓相同：靠提手与锁梁的粗细、锁孔区分。

## 2. 画布、关键形状和尺寸

- 活动区为 14×14（1..15），四周各留 1，任何内容不得超出。
- 每个图标选一个关键形状，写在 `key` 中。整体轮廓（含凸起、提手、立柱、蝴蝶结）正好填满该形状：

| key | 尺寸（位置） | 用于 |
| --- | --- | --- |
| `circle` | 直径 14，圆心 (8, 8) | 表盘、脸、球 |
| `square` | 13×13（1.5..14.5） | 日历、相机、用户、建筑、铃铛、礼物、归档盒 |
| `landscape` | 14×12（y 2..14） | 文件夹、证件、书、图片、钱包、对话 |
| `wide` | 14×11（y 2.5..13.5） | 长边是短边 1.4 倍以上的物体：票、云、电池、信封 |
| `portrait` | 12×14（x 2..14） | 文件、锁、垃圾桶、话筒、购物袋 |
| `tall` | 10×14（x 3..13） | 本身瘦高的物体：手机、瓶子。按 12×14 画会被认成平板 |
| `flat` | 14×8（y 4..12） | 靠又长又矮的轮廓识别的符号：链接、滑块。按 14×11 画，链接会像圆圈里的减号 |
| `live` | 14×14 | 左右分开的物体，如耳机 |

- 内部细节放在中心直径 8 的范围内。
- `square` 图标在 12×12 的框内（2..14）绘制，渲染时以中心放大到 13×13，使方形与矩形面积相当；描边和缝宽会换算回原值，粗细不变。
- 坐标不必对齐整数像素，可以落在 0.5、0.25 上。
- 横向物体不画成 14×10，竖向物体不画成 10×14，否则前者显扁、后者显瘦。只有本身就长的物体用 `wide`。
- 实心图标比同尺寸的线性图标显得大，轮廓略小于线性图标的外框是正常的，不要为了填满而放大。

## 3. 颜色

- **主体一律用辅色。** 物体本身（纸、盒子、表盘、钱包、文件夹、气泡、话筒头）为浅色，写 `Bt`。
- **主色只用于点缀。** 主色只用在说明身份的关键部件和细节上：锁梁和锁孔、镜头圈、字线、指针、扣子、电量格、提手、耳罩、话筒支架、蝴蝶结和丝带。
  - 主色只是细节（线、点、指针、小部件）时，通常约占着色面积的三分之一或更少。
  - 主色是物体的大部件（屏幕、信封盖、耳罩、伸出的纸、放大镜圈）时，可以更多。
  - 任何情况下不超过 60%。
- **印在主体上的细节与主体直接相接，不留白缝**，靠深浅区分。分开的元素，以及跨过另一元素边缘的元素，无论颜色，都按第 6 节处理：间隔一个线宽，或用白色描边蒙版切开。
- **白色只用于两处：**
  - 几何上分开一个物体的缝，如盖子与箱体、书的两页、票与票根。
  - 主色部件上本来就是孔的地方，如镜头中心、钱包扣的扣眼。
- 默认配色：主色 `#5A76F2`，辅色 `#BDC8FA`（主色以 40% 不透明度叠在白底上）。更换品牌色时，用 `secondary(主色)` 推导辅色，不另行挑选。
- 辅色必须是主色同色相的浅色，不用灰色，也不得比 40% 更浅；更浅时，浅色主体在 16px 下轮廓不清，白缝也难以分辨。

## 4. 圆角

**4.1 半径按角在物体上的位置确定，不统一用一个值。** 尺寸按绘制时的数值计算，`square` 图标按放大前的 12×12 计算。

| 角的位置 | 半径 | 常量 | 例子 |
| --- | --- | --- | --- |
| 横向主体（14×12，`landscape`）的外轮廓角 | 3 | `R3` | 证件、图片、钱包、书、对话 |
| 其他主体，短边 9.5 及以上 | 2.5 | `R` | 文件夹、相机、日历、建筑、电池、票、信封、箱体底部、购物袋 |
| 竖向主体（12×14 的纸、书本），以及短边 6 到 9.5 | 2 | `M` | 文件、锁体、打印机机身 |
| 短边 3.5 到 6 | 1.5 | `r` | 凸起、票根、耳罩、盒底、证件照片 |
| 短边小于 3.5 的小部件（门、烟囱、把手、箭杆） | 不超过短边的一半，常用 0.5–1 | | 门的上角用 1，箭杆两端用半圆 |
| 切缝：一条缝笔直穿过同一轮廓，两侧对齐 | 0 | | 书的两页、票与票根 |
| 接缝：窄部件位于宽部件旁，隔缝露出自身的角 | 1 | `S` | 盖子下方的箱体、袋口 |
| 薄片：盖子、横条、底座 | 厚度 × 0.4，按 0.25 取整 | `q`、`t` | 厚 1.5 用 0.5，厚 2 用 0.75，厚 2.5 用 1，厚 3.5 用 1.5 |
| 内角：凸起与主体相接处 | 0 | | 文件夹标签、相机顶部、盖子把手 |
| 孔 | 外圆角减壁厚 | | |
| 本身是圆形的部件 | 整圆、半圆、胶囊 | `circ`、`pill` | 表盘、脸、话筒头、铃铛、肩部、线头 |

- 外轮廓圆角约为物体短边的 0.24 倍；竖向的纸和书本小一档，显得挺括。
- 除线头和极小的细节外，不用小于 1 的圆角。小圆角过多会使整套图标显得琐碎。
- 切缝两端保持直角，使缝看起来是一条切线；两端加小圆角会在轮廓上留下缺口。
- 不加倒角。凸起与主体相接处保持直角，加倒角会使部件之间分界不清。
- 同一部件不得随意一边圆、一边方。仅以下三种情况例外：切缝两侧、接缝两侧，以及从开口伸出、被开口截断的一边（打印机送出的纸，见 `printer`）。
- 每个部件都用大圆角时，物体会显得松散。物体被分成几部分时，整体外轮廓仍须是一个完整的圆角形。

**4.2 平滑圆角。** `kit.mjs` 的 `poly` 已实现平滑圆角，直接使用 `rr`、`body`、`pill`，不要自行绘制圆弧角。做法与 Hugeicons 相同：每个角由两段曲线组成，曲线从距角 1.8 倍半径处开始，中点落在同半径圆弧经过的位置。视觉上就是该半径，且与直边相接处没有折点。

## 5. 细节

- 线和槽宽 1.25（`D`），成组的点半径至少 0.625，描边 1.5（`K`：锁梁、提手、指针、箭杆），细支架 1.25（话筒支架、耳机头梁）。以浅色描边构成的主体（链接的两个半环）用 2，否则在 16px 下轮廓不清。
- 印在主体上的小细节（线、点、槽、小标记）距主体边缘约 3，至少 2。物体本身的部件（屏幕、信封盖、从顶边垂下的书签带、伸出的纸、立在底边上的门、开关的拨钮）属于轮廓，可以贴边，不受此限。
- 一个面上最多两到三条线：文件三条，书每页两条，对话两条。
- 细节宜轻。线过粗、点过大、离边过近，都会显得粗糙。
- 表盘类（时钟、笑脸）为浅色表面，指针和五官用 1.25–1.5 的主色线条，不加外框；加外框会像线性图标。

### 5.1 小部件的最小尺寸

在 22–24px 的列表和标签栏中，单独的小部件最容易显得过小。下限按部件的角色分为三类，均以 16 网格中实际绘制的尺寸计算，参照 Solar Bold Duotone 和 Duo Icons 测得。

| 角色 | 例子 | 下限 |
| --- | --- | --- |
| 单独的小标记 | 锁孔、铃铛的钮和铃锤、门 | 面积至少 4：圆点直径至少 2.25，槽至少 1.5×3 |
| 单独的一条线 | 文件夹上的标签、证件和手机上的线 | 长度至少 3，宽 1.25 |
| 成组的部件（两个及以上同样大小） | 日历格点、窗户、书页文字、眼睛 | 点直径至少 1.25（面积 1.25），线长至少 2.25 |

- 面积 8 以上的属于部件而非细节，不受此表限制。
- 放不下的细节直接删除，不要缩小。若离边至少 2 的要求与此表冲突，说明该细节不是识别物体所必需的，例如相机的闪光灯、打印机的指示灯，应删除。
- 放大时保持物体原有的形状：铃铛的钮是圆形，铃锤是半圆，不要只把原来的小块拉宽拉长。
- 自检的 `size` 规则测量每个主色小部件，并按上表判断。

## 6. 间距、遮挡和对齐

- **分开的元素之间间隔一个线宽 `W`，即正好为 1。** 相接（0）、间隔不足（如 0.5）和间隔过大（2 及以上）都不允许。例如头与身体、盖子与箱体、书的两页、票与票根、蝴蝶结与盒盖、购物车的车筐与车架、话筒头与支架。
- **一个元素压在另一个元素上时，前面的元素加一圈宽 `W` 的白色描边蒙版（`gap: W`），切开后面的元素。** 两者同样间隔一个线宽，前后关系也清楚。例如：
  - 云挡住太阳。
  - 锁体挡住锁梁，袋身挡住提手。
  - 耳罩挡住头梁，镜片挡住放大镜手柄。
  - 符头挡住符干。
  - 箭头压在盒子上（下载、上传、分享）。
  - 日历的立柱、铃铛顶部的钮、定位的刻度跨过主体边缘。
  - 打印机送出的纸压在机身上。
- 叠放须有明确的遮挡关系：后面的元素被遮住约四分之一到三分之一。只擦到边缘的叠放看不出前后关系（见 `cloud`）。
- 一个元素由几层组成时（箭头的箭杆和头部），这几层写同一个 `part`，它们的蒙版不会相互切开。
- 以下情况不算分开的元素，不受本节间距规则限制：
  - 完全印在主体内的细节（字线、点、指针、表情、窗条、立在底边上的门）。
  - 用 `clip` 从主体截出的部分（信封盖、笔尖）。
  - 同一主体上主色细节之间的距离（眼睛与嘴），按第 5 节处理。
- **相关元素对齐。** 相关的元素对齐到同一条中线或同一条边：
  - 分享、下载、上传的箭杆落在盒子的中线上。
  - 门、锁孔、钮、铃锤、底座落在主体的中线上。
  - 成对的部件（耳罩、轮子、眼睛、窗条）以主体为中心对称，例如购物车的两个轮子以车筐为中心。
  - 一组细节（字线、点）左对齐，间距相等。
- **嵌在主体内的部件，到相邻各边的距离相等。** 相邻指距离在 2.6 以内。位于圆头内的圆与圆头同心：开关的圆钮距轨道上、下、外侧都是 1，不能上下 0.75、侧边 1.5。位于角上的部件距两条边相等：图片中的太阳距上边和右边都是 2.25。只靠近一条边的部件（锁孔、字线）居中或左对齐即可。挂在边上或立在边上的部件（书签带、门）属于轮廓，不在此列。

## 7. 切割

- 一个物体最多分成两到三部分，如盖子与箱体、头与身体。各部分不再继续切分。
- 丝带、指针、字线等细节直接印在主体上，不用白线切出。

## 8. 写法

- 新图标按 `icons.mjs` 的格式追加：

  ```js
  名字: {
    label: '中文名',
    key: 'landscape',
    layers: [
      L(rr(1, 2, 14, 12, R3), Bt),            // 浅色主体
      L(pill(9.5, 6.25, 4.5, 3.5))            // 主色部件
    ]
  }
  ```

- `layers` 按从后到前的顺序书写：通常先写浅色主体，再写主色部件和细节。现实中浅色部件在前时，浅色层写在后面，例如太阳在云后（`cloud`），音符的符头压住符干（`music`）。
- 工具函数：
  - `rr(x, y, w, h, 半径或[左上, 右上, 右下, 左下])`：圆角矩形。
  - `polygon([[x, y], ...], 半径或每点一个半径)`：多边形，顶点按顺时针给出，每个角按第 4 节平滑。只用于第 1 节例外中的斜边，如屋顶、箭头头部、播放三角。
  - `rot(cx, cy, w, h, 角度, 半径)`：以 (cx, cy) 为中心旋转的圆角矩形，用于放大镜手柄、齿轮的齿、斜放的笔。
  - `pill(x, y, w, h)`：胶囊。
  - `circ(cx, cy, r)`：圆。
  - `body(x, y, w, h, 半径, [{ x, w, h, c }])`：顶边带凸起的主体。
  - 描边写 `L(路径, { sw: K })`，镂空写 `cut: [C(形状)]`。
  - `clip: 形状`：只绘制该层落在形状内的部分。用主色画主体的一部分时使用，部件与主体的圆角完全一致，例如信封盖是主体被一个圆截出的上半部分（见 `mail`）。不要用全画布矩形加反向路径拼凑。
  - `gap: W`：在该层轮廓外切出一圈宽 `W` 的白缝，切开其下方的层。前面的元素压在后面的元素上时使用（第 6 节）。
  - `part: '名字'`：同一元素的几层写同一个名字，它们的 `gap` 不会相互切开。
  - `badge(图标, 角标, 选项)`：生成带角标的变体（第 12 节）。
- 绘制前先阅读一两个结构最接近的范例：
  - 带盖的物体：垃圾桶、归档盒。
  - 一分为二的物体：书、票。
  - 带凸起的主体：文件夹、相机。
  - 表盘：时钟、笑脸。
  - 箭头类：下载、上传、分享。斜放的物体：编辑（笔）、搜索。由斜边组成的：首页、播放、心形。
  - 瘦高的：手机（`tall`）。扁长的：链接（`flat`）。
  - 主体的一部分用主色：信封。从开口伸出物体：打印机。
  - 带提手或锁梁：锁、购物袋。
- 经确认属于有意为之的检查结果，可在图标中写 `allow: { 规则名: '理由' }` 声明，例如话筒立柱的顶端藏在支架后面。未经确认的不得声明。

## 9. 自检

```bash
node check.mjs --only 新图标A,新图标B --with folder,lock,calendar
```

输出在 `check-out/`：

- `sheet.png`：64px（带像素网格）、48、24、16px。
- `keylines.png`：每个图标叠加在参考线上，红线为其关键形状。
- `px16.png`：1 倍屏下实际的 16px，放大 4 倍。
- `findings.md`：可量化规则的测量结果：
  - `keyline`：轮廓未填满关键形状（相差 0.25 以上）。
  - `primary`：主色超过着色面积的 60%。
  - `tones`：只用了一种颜色。
  - `spacing`：分开的元素间隔不是 1（包括相接）。角标的缺口边按实际绘制的形状测量。
  - `overlap`：一个元素压在另一个元素上，但没有白色描边蒙版。
  - `size`：主色小部件小于第 5.1 节的下限。
  - `inset`：嵌在主体内的部件到相邻各边的距离不等（相差超过 0.15）。
  - `motion`：`motions.mjs` 中的动效引用了图标中不存在的层。
  - `reach`：悬停动效在某一帧超出画布（0–16）。

`findings.md` 中的 Findings 必须清空：修改图标，或经确认后用 `allow` 声明。然后对照截图逐条检查：

1. 在 24px 和 16px 下能认出是什么，不会被认成别的物体（第 1 节）。
2. 轮廓填满关键形状，与 `--with` 带入的范例看起来一样大。
3. 主体为浅色，主色只用于关键部件和细节，两色之间没有白缝。
4. 每个角的半径符合第 4 节；没有尖角、倒角，没有随意的一边圆一边方。
5. 细节的线宽、点径、离边距离符合第 5 节，小部件不小于第 5.1 节的下限，一个面上不超过三条线。
6. 分开的元素间隔正好为 1；压在其他元素上的元素带 `gap: W`；相关元素对齐，成对部件对称；嵌入的部件四周边距相等。
7. 物体最多分成两到三部分。

## 11. 动效

在网页中，图标在悬停时播放动效，没有入场动效。运行代码在 `motion.mjs`，各图标的动作写在 `motions.mjs`。导出的静态 SVG 不含动效。

- **动作表现图标的含义。** 先确定图标代表的事情，再让物体完成这件事。例如：
  - 盖子掀开，日历撕下一页，书翻过一页，礼物的盒盖连同蝴蝶结掀起。
  - 箭头从盒子或门中伸出（下载、上传、退出登录）；分享的箭杆从盒子中画出，画完后箭头弹出。
  - 文字逐行写出，对勾、叉号按笔画重写一遍。
  - 大楼的窗户由下而上逐层亮起，电池逐格充满，信号由内向外发出。
  - 滑块滑到另一端，地球自转一周，眼睛眨一下再左右看。

  不使用与含义无关的放大、缩小或脉动。
- **部件可以出现和消失。** 静止时没有的部件可以在悬停时出现，例如：
  - 相机的闪光、手机两侧的振动线、话筒两侧的声波。
  - 定位的波纹、录像的录制灯、灯泡内亮起的灯丝。
  - 落入收件箱的信。

  已有部件也可以消失后再出现（`a` 控制不透明度），描边可以重新画出（`w`）。静止时藏在主体后面的部件（文件夹里的纸）也可以这样使用。
- **幅度不得超出画布。** 动效的每一帧，所有部件都留在画布（0–16）内。图形已占据 1–15，方形图标还略有放大，余量只有约一个单位：
  - 掀盖子以抬起加小角度为主，不绕一端大幅转动（长盖子转 6°，末端就会抬高 1 以上）。
  - 平移不超过 1。
  - 向外伸出的部件从画布内部开始伸出。
  - 旋转用绕竖直轴的翻转（`sx` 从 1 到 -1 再回到 1，像钥匙扣打转），只在水平方向收放。

  靠近边缘的停留值用关键帧给出（例如 `y: [-1, -1]`），避免回弹时超出画布。自检的 `reach` 规则逐帧检查。
- **停留姿态须一眼看懂。** 悬停时停留的姿态，应比静止时更能说明图标的含义，至少不能令人困惑。做不到时，动作完成后回到静止姿态（最后一个关键帧取静止值）。已出现过的问题和改法：
  - 信封盖向上翻起，停留时像一顶帽子；把封口折到后面，信封又只剩一个方块。改为：信封保持完整并整体下移，一张带线的浅色信纸从后面抽出。
  - 门打开后只剩一条窄缝，看不出是门。改为：门推开后再关上。
  - 扣带滑出主体，像多出一块。改为：从钱包里抽出一张卡。
  - 托盘里多出一个带框的方块，看不出是信。改为：浅色纸加一条线，下半截藏在托盘前沿后面。
  - 灯泡中间多出一个色块。改为：整个玻璃泡变为主色，高光改为浅色。

  检查方法：把每个图标的静止姿态和停留姿态并排比较，并在 22px 的列表中查看停留姿态；22px 下看不清的部件（如封口的两片细边）不要使用。
- **部件按现实中的连接方式运动。** 盖子绕铰链转动，提着的袋子绕提手摆动，几个部件可以各自运动（两根指针速度不同，两个耳罩各自向内夹）。原本在同一层、需要分开运动的部件，拆成几层；拆分后外观不变。
- **节奏。** 悬停时 480ms，曲线 cubic-bezier(.34, 1.56, .64, 1)，略过头后回弹，然后停留在悬停姿态。移开后 360ms 退回，不回弹。带关键帧的动作，关键帧按时间均分，每多一段加 110ms；手机振动这类快速抖动用 `ms` 单独指定总时长。
- **写法。** `MOTION[名字] = { say, moves, copy?, add?, ms? }`：
  - `say`：一句中文，说明图标的动作。
  - `moves`：将层号（`all` 表示整个图标）映射到一个姿态。可用的键：`x`、`y`（移动），`r`（旋转），`s`、`sx`、`sy`（缩放），`a`（不透明度），`w`（描边画出的比例），`o`（旋转和缩放的中心），`rest`（静止姿态，如只在悬停时出现的部件写 `rest: { a: 0 }`）。每个键的值可以是停留值，也可以是一组关键帧。
  - `copy: [{ of: [层号] }]`：复制若干层覆盖在原位，用于表现"下面还有一页"。撕下或翻走的是复制层（见 `calendar`、`book-open`）。在 `moves` 中称为 `c0`、`c1`……
  - `add: [{ layer, at? }]`：只在动效中出现的部件，用 `kit.mjs` 的工具绘制。在 `moves` 中称为 `a0`、`a1`……，需配 `rest: { a: 0 }`。需要与其他部件隔开时写 `gap: W`。
- **自检。**
  - `check.mjs` 的 `motion` 规则检查动效引用的层是否存在，`reach` 规则检查是否超出画布。
  - 动作本身需要在页面中逐个悬停检查，不能只看静态截图：动作是否表现含义，白色描边蒙版是否随部件移动，移开后是否回到原样，悬停时出现的部件移开后是否消失。

## 12. 角标和变体

同一物体的不同状态或操作（新建、完成、删除、减少、AI、关闭），用"物体 + 一个角标"表示，物体本身不变。一组变体放在一起时，能看出是同一物体的不同状态。用 `kit.mjs` 的 `badge()` 生成：

```js
'folder-plus': badge(ICONS.folder, 'plus', { at: [8, 9], drop: [0, 2], label: '新建文件夹' }),
'search-sparkle': badge(ICONS.search, 'sparkle', { drop: [2], label: 'AI 搜索' }),
'bell-off': badge(ICONS.bell, 'off', { label: '免打扰' })
```

- **角标只有六种：** `plus`（新建、添加）、`minus`（减少、移除）、`check`（完成、已确认）、`x`（删除、失败）、`sparkle`（AI、智能）、`off`（关闭、静音、隐藏）。均用主色，线宽 `K`，置于 4.5 的方框内（星光为 6），因此在任何图标上大小一致。不另画其他角标，也不缩小。
- **位置：**
  - 物体正面有完整的浅色区域时（文件夹、日历、剪贴板、锁），角标放在正面中央，替代物体原有的细节（用 `drop` 去掉），不加白缝。四周边距须相等（第 6 节的 `inset`）。
  - 正面放不下时，放在关键形状的角上：加号、减号、对勾、叉号在右下角，星光在右上角。角标中心距关键形状的两条边各 3，不超出关键形状。角标在物体上切出半径 4 的圆形缺口（角标伸出的 3 加白缝 1），缺口内不留物体的碎片。缺口边为直切，转角为 0。
  - `off` 是一条 45° 斜线，从关键形状的左上角到右下角，两侧各留 1 的白缝。
- **被缺口切断的细节整个删除。** 物体的小部件被缺口切去一部分时，用 `drop` 整个去掉（例如图片的太阳让位给星光）。其余部件仍须满足第 5.1 节的最小尺寸。
- **主色占比不得因角标超标。** 物体本身主色已较多时（例如用户的头部），加号会使主色超过 60%。此时改用笔画较少的角标（对勾、减号），或将角标放在正面。
- **动效由角标完成。** 加号、叉号绕自身中心转 90°，对勾和斜线重新画出，星光缩小后放大并转动。物体本身不动，除非其原有动作与变体含义一致（例如"已认证用户"仍然抬头）。角标中心记录在该层的 `at` 中，作为旋转中心。
- 范例：`folder-plus`、`calendar-check`、`clipboard-check`、`user-check`、`search-sparkle`、`image-sparkle`、`bell-off`、`eye-off`。
